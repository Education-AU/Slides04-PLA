---
title: Matrix representation of a Linear map
template: default
---


Any linear map between finite dimensional vectorspaces can be coordinatized by a matrix **in specifically chosen
bases**.


And any matrix induces a linear map in some **specifically chosen bases**


Many of the concepts we study can be expressed using matrices.
However, matrices depend on a chosen basis, while the underlying linear maps do not.

To avoid unnecessary technicalities, we will primarily state general theorems basis-free, and only introduce matrices
when they help clarify or compute concrete examples.
