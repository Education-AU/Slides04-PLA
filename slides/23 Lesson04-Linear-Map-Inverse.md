This property actually holds for any map, not just linear maps.

### Surjectivity

Surjectivity $L\Leftrightarrow \operatorname{range}(L)=W$



Assume $\operatorname{range}(L)=W$ then for all $\mathbf{w}\in W$ there exists a $\mathbf{v} \in V$ such that $L(\mathbf{v})=\mathbf{w}$ implying surjectivity.



Conversely, assume $L$ is surjective then for all $\mathbf{w}\in W$ there exists a $\mathbf{v}\in V$ such that $L(\mathbf{v})=\mathbf{w}$ which implies $\operatorname{range}(L)=W$
