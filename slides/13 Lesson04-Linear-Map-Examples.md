First of all is it a map?

If $f \in C^2[a,b]$ the derivative exists, and it is continuous by assumption. So $D$ is a map.

Is it linear

Let $f,g \in C^2[a,b], s \in \mathbb{R}$

$$
\begin{aligned}
D(f+g)&=(f+g)'=f'+g'=D(f)+D(g)\\
D(sf)&=(sf)'=sf'=sD(f)
\end{aligned}
$$

So the map is linear

What about $f''$ differentiation two times??

We can use that $f''$ is the same as $D^2=D\circ D$ so by composition it is linear.

We must be careful about spaces though!
